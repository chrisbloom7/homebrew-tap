# Chrisbloom7 Tap

## How do I install these formulae?

`brew install chrisbloom7/tap/<formula>`

Or `brew tap chrisbloom7/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "chrisbloom7/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
